Radio & broadcast studio

Media Engine, inside your dashboard.

Upload ministry audio or video

Files without permanent retention expire after 48 hours. Publish an uploaded file below to add it to the public radio or video playlist.

Uploads use small resumable parts. If interrupted, select the same file and resume within 24 hours. MP4 with H.264/AAC and MP3 offer broad playback support.

Schedule a programme

Immediate ON AIR source

Take over the current 24/7 programme with an uploaded/recorded video or a supported external HTTPS/YouTube source. For camera, picture, screen and branded live production, use Studio.

If the live connection drops, this selected standby video plays automatically during the reconnect window. Uploading a standby advert does not add it to the 24/7 playlist. When live returns, viewers return to live automatically.

During a manual external live programme, keep this dashboard available so the heartbeat stays healthy. Short network interruptions are protected by the reconnect window and standby advert/fallback system.
