# KJV text provenance

Edition: eBible.org eng-kjv2006, standardized 1769 KJV, 66-book protocanon. Text courtesy of Crosswire Bible Society and eBible.org.

Source page: https://ebible.org/bible/details.php?id=eng-kjv2006
Source archive: https://ebible.org/Scriptures/eng-kjv2006_vpl.zip
Archive SHA-256: ae1f46afef704d5a97c9fdc5bdcdc2b296643eb819ad7f5dc88e45b6233205b7

The source labels this edition public domain outside the UK and describes a UK restriction on printing/importing printed copies. This web bundle reproduces the source verse text unchanged, including source paragraph symbols and bracketed italic-word notation. No Apocrypha or Strong's annotations are added. Do not describe other translations or recordings as covered by this text source.

The build validates source hash, book/chapter order, sequential verse numbers and totals of 66 books, 1,189 chapters and 31,102 verses. Generated book hashes are in the manifest. Run python bible/scripts/build-kjv.py /path/to/source.zip to reproduce. Run node bible/tests/scripture.mjs and node bible/tests/reader.cjs to verify locally.
