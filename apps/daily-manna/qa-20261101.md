# Daily Manna staging verification

A separate local staging package was tested against a SQLite adapter matching the D1 query methods. It verifies draft creation, duplicate dates, month filtering, authentication, stale revision rejection, approval, Lagos midnight release, duplicate prevention, outbox reconciliation, and audit records. No live Cloudflare deployment was performed. Source REV252 contains 1,826 entries, all imported as unapproved drafts. The staging SQL uses deterministic UUIDs for compatibility with editor routes. The full import must be reviewed before use.
